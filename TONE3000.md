# TONE3000 rig notes

Living log of the TONE3000 side of the rig: what each preset is built from and
why. `tone3000.py` is the source of truth; this file explains the choices.

## Global settings (every preset)

| Setting | Value | Why |
|---|---|---|
| Output level | +24 dB (max) | user preference |
| Noise gate | on, −35 dB | user preference; SW6 / CC 20 toggles it |
| NAM size | A2-Full | highest accuracy |
| Oversampling | 2× | 0 xruns at 128 samples; 4×/8× produced xruns (see below) |
| Input | Scarlett 2i2 Input 2, mono, calibrated at 12.5 dBu | guitar lives on Input 2; calibration assumes gain knob at minimum |
| Audio | JACK (pipewire-jack) 48 kHz / 128 | launcher sets `PIPEWIRE_QUANTUM=128/48000` |

### Buffer / oversampling benchmark (i7-1365U, performance profile, AC)

| Buffer | Oversampling | Peak DSP (B/Q) | Xruns |
|---|---|---|---|
| 128 (2.7 ms) | 2× | 0.30 | 0 in 60 s |
| 128 | 4× | 0.20 | 2 in 20 s |
| 128 | 8× | 0.30 | 3 in 15 s |
| 64 (1.3 ms) | 2× | 0.19 | 12 in 30 s |
| 64 | off | 0.30 | 4 in 60 s |

Retest 64 once the session has the `realtime` group (log out/in).

## Footswitches (global, by block position)

SW6 gate · SW7 spread (stereo chorus-ish) · SW8 block 1 · SW9 block 2 ·
EXP A treble sweep · EXP B output level. In the standard chain block 1 is a
Klon lead boost and block 2 the song's drive; custom chains keep block 1/2 as
the two switchable pedals.

## Purple Rain (PC 1)

**The original.** Recorded live at First Avenue, Minneapolis, 3 Aug 1983;
overdubs and mix at Sunset Sound. Prince: Hohner "MadCat" (Tele-style, single
coils) → Boss pedals (DS-1 / SD-1, CE-2 chorus, DM-2 delay, BF-2, OC-2) →
Mesa/Boogie Mark II (IIB, some sources IIC+) → Bag End cabinets with JBL
12s. Clean chorused arpeggios, a huge plate, DS-1 for the outro solo.

**Chain.**

| Block | What | State | Switch |
|---|---|---|---|
| 1 | Boss DM-2 style echo — generated IR: 300 ms (DM-2 max), BBD low-pass per repeat, wet 35% | off | SW8 (DLY) |
| 2 | Boss DS-1, Tone 4 / Dist 8 | off | SW9 (DIST) |
| 3 | 1984 factory Mesa Mark IIC+ "Silver Zephyr", Dynamic Airy Edge (DI), with humbucker→single-coil pre-EQ for the MadCat | on | — |
| 4 | JBL E120 12" IR, SM57 cap edge | on | — |
| 5 | EMT 140 plate at **Sunset Sound** (the Purple Rain mix room), wet, trimmed to 5 s mono, 30% | on | — |
| — | Spread (stereo, wobble 0.5) as the CE-2 chorus | on | SW7 |

**Gaps.** No Mark IIB capture exists on TONE3000, so the IIC+ (its direct
successor) stands in. The CE-2 is time-varying and can't be captured, so Spread
approximates it. The DM-2 echo is synthesized, since no DM-2 IR exists.
