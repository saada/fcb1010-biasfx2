# TONE3000 rig

The native Linux TONE3000 plugin (NAM captures + IRs) running the FCB1010 rig:
15 song presets, each researched to match the band's best-era record/live
guitar sound, built from free TONE3000 catalog captures.

- **Presets, chains and capture links:** [rigs/RIGS.md](rigs/RIGS.md), generated from `rigs/*.json`
- **File format / slot rules:** [rigs/README.md](rigs/README.md)
- **Measurements and A/B tests:** [experiments/README.md](experiments/README.md)
- **Fresh machine:** `./bootstrap.sh [TONE3000-*-linux-x64.tar.gz]` (downloads the pinned release if none is given)
- **Plugin version:** TONE3000 **v0.0.12** (`T3K_VERSION` in bootstrap.sh). Older builds glitch the
  IR-heavy presets in Qtractor (experiments D15). Rollback = reinstall the older tarball; presets
  written by `tone3000.py build` (v2 `T3KH` framing) need v0.0.10 or later.

## Global settings (`tone3000.py configure`)

| Setting | Value | Why |
|---|---|---|
| Audio | JACK (pipewire-jack) 48 kHz / **256** samples | 0 xruns on the stereo rigs; 128 crackled (experiments L2–L3) |
| Oversampling | off | 2×/4×/8× added xruns (L1, L3) |
| Multi-core | on | off = 50–350 xruns/min (L2) |
| NAM size | A2-Full, default for new blocks too | highest accuracy |
| Input | Scarlett Input 2, mono, NAM calibration 12.5 dBu | calibration assumes the gain knob at minimum |
| Output | 0 dB | +24 dB hard-clipped the interface (L4); the DAW rig's EXP B is a Qtractor gain stage, not this knob (D22) |
| Gate | on, −60 dB, release 100 ms, hold 50 ms, range 80 dB | −35 dB chopped note decays (L4); release/hold are v0.0.9's fixed values (0.0.11+ defaults to 50/20 ms) |

## Footswitches

| FCB1010 | CC | TONE3000 |
|---|---|---|
| SW1–5, banks 00–02 | PC 0–14 | presets |
| SW6 | 20 | noise gate |
| SW7 | 21 | stereo spread (chorus-like movement) |
| SW8 | 22 | slot 1: lead boost |
| SW9 | 23 | slot 2: drive |
| SW10 | 24 | slot 5 + R3: solo echo (both sides of dual rigs) |
| EXP A | 27 | treble sweep |
| EXP B | 7 | not mapped: volume is a DAW gain stage before the limiter (D22) |

On the BIAS FX 2 side the same CCs mean wah / octaver / delay / distortion /
tuner (see TONES.md), so the pedal itself never needs reprogramming.

## What TONE3000 can't do (and the stand-ins)

- Time-varying effects (chorus, flanger, phaser, wah, rotary) can't be captured, and v0.0.12 has
  no modulation or wah block → Spread/Align wobble, or the DAW's pedals.
- Pitch: v0.0.12 has a **pitch shifter** (±24 semitones, whole steps or a smooth whammy sweep,
  `pitch*` preset params, MIDI-mappable). It is global (input stage, before both chains), replaces
  the dry signal (no blend) and has no scale awareness, so an octave *under* the dry guitar or a
  diatonic harmony still needs a second instance or the DAW. Off in every preset.
- No built-in delay/reverb → delays are generated BBD-style echo IRs; reverbs are catalog plate/hall/room/spring IRs.
- IRs that aren't 48 kHz, or have an odd-length data chunk, load silently → the builder re-encodes them (experiments I1–I2).
